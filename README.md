# Frontier Realms / 辺境諸国戦記

ブラウザで遊べるターン制ストラテジーゲームのプロトタイプです。

## 現在遊べる内容

- 16 × 10マスの地形マップ
- 赤・青・緑・黄の4陣営から選択
- 平原・森林・丘陵への初期村設置
- 隣接する土地の占領
- 地形・建物に応じたターン収入
- 村から街、街から城への発展
- 農場、製材所、採石場、市場、兵舎の建築
- 兵舎での徴兵と部隊編成

## 開発

Node.js 22.13以降を使用します。

```bash
npm install
npm run dev
```

本番用の確認:

```bash
npm run build
```

## オンライン対戦について

現在の版はゲームルールを確認するための一人用プロトタイプです。
オンライン対戦化する際は、部屋情報・プレイヤー・ターン・領土・資源を
サーバー側データベースへ保存し、各クライアントから同期します。
